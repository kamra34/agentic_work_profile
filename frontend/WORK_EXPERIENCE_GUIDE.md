# Work Experience Guide - New Structure

## Overview

The Work Experience section has been restructured to match typical resume patterns with clear hierarchy and optional bullet grouping.

## Structure

```
Work Experience Section
└─ Job Entry (Level 0)
   ├─ Job Title: "Lead Data Scientist & AI Delivery Lead"
   ├─ Company: "ERICSSON"
   ├─ Location: "Stockholm, Sweden"
   ├─ Dates: "Nov. 2019 - Present"
   ├─ Description: Optional intro paragraph
   │
   ├─ Direct Bullet Points (Simple approach)
   │  ├─ • Bullet 1
   │  ├─ • Bullet 2
   │  └─ • Bullet 3
   │
   └─ Bullet Groups (Optional - for organization)
      ├─ Group: "Delivery & Stakeholder Management"
      │  ├─ • Bullet 1
      │  ├─ • Bullet 2
      │  └─ • Bullet 3
      ├─ Group: "Technical Leadership"
      │  └─ • Bullets...
      └─ Group: "Key Achievements"
         └─ • Bullets...
```

## How to Add a Job

### Step 1: Add Work Experience Section
1. Click "+ Add Section"
2. Select "Work Experience" 💼

### Step 2: Add a Job
1. Expand the Work Experience section
2. Click "+ Add Job" (green button)
3. Fill in the form:
   - **Job Title*** (required): "Lead Data Scientist & AI Delivery Lead"
   - **Company**: "ERICSSON"
   - **Start Date**: "Nov. 2019"
   - **End Date**: "Present"
   - **Location**: "Stockholm, Sweden"
   - **Description** (optional): Intro paragraph about your role
4. Click "Save Job"

### Step 3A: Add Direct Bullet Points (Simple)
If you don't need to organize bullets into groups:

1. Expand the job entry
2. Click "+ Add Bullet Point"
3. Type your achievement/responsibility
4. Press Enter to save
5. Repeat for more bullet points

**Result:**
```
Lead Data Scientist & AI Delivery Lead
ERICSSON | Stockholm, Sweden | Nov. 2019 - Present
• Directed AI and data science programs...
• Led cross-functional teams...
• Developed advanced ML pipelines...
```

### Step 3B: Add Bullet Groups (Organized)
If you want to organize bullets by category (like in your resume):

1. Expand the job entry
2. Click "+ Add Bullet Group (Optional)" (yellow dashed button)
3. Enter group title: "Delivery & Stakeholder Management"
4. Press Enter
5. The group appears - expand it
6. Click "+ Add Bullet Point" under the group
7. Add your bullets for this category
8. Repeat for more groups: "Technical Leadership", "Key Achievements", etc.

**Result:**
```
Lead Data Scientist & AI Delivery Lead
ERICSSON | Stockholm, Sweden | Nov. 2019 - Present

Delivery & Stakeholder Management
• Defined delivery roadmaps...
• Coordinated with SI partners...
• Collected and translated business requirements...

Technical Leadership
• Guided teams in applying data science...
• Mentored contributors...

Key Achievements
• Delivery Impact: Successfully managed...
• Leadership Recognition: Awarded...
```

## Visual Indicators

- **Job Entry (Level 0)**: Purple left border
- **Bullet Group (Level 1)**: Green left border, indented
- **Add Bullet Group**: Yellow dashed button with 💡 tip

## Tips

### When to Use Bullet Groups?
- ✅ **Use groups** when you have many achievements organized by theme
- ✅ **Use groups** when you want to highlight different aspects of your role
- ✅ Examples: "Technical Leadership", "Delivery Management", "Key Achievements"

### When to Use Direct Bullets?
- ✅ **Use direct bullets** for simple, short job descriptions
- ✅ **Use direct bullets** when you have fewer than 5-6 bullet points
- ✅ **Use direct bullets** for straightforward roles

## Auto-Refresh

All changes now auto-refresh! No need to manually reload:
- ✅ After saving a job
- ✅ After adding bullet points
- ✅ After adding bullet groups
- ✅ After deleting anything

## Example Workflows

### Example 1: Simple Job Entry
```
1. Add Job: "Software Engineer" at "Google"
2. Add 3-4 direct bullet points
3. Done!
```

### Example 2: Complex Job Entry (Like Your Resume)
```
1. Add Job: "Lead Data Scientist & AI Delivery Lead" at "ERICSSON"
2. Add Bullet Group: "Delivery & Stakeholder Management"
   - Add 3-4 bullets
3. Add Bullet Group: "Product Management"
   - Add 3-4 bullets
4. Add Bullet Group: "Technical Leadership"
   - Add 2-3 bullets
5. Add Bullet Group: "Technical Contribution"
   - Add 4-5 bullets
6. Add Bullet Group: "Key Achievements"
   - Add 3 bullets
7. Done!
```

### Example 3: Multiple Jobs at Same Company
```
1. Add Job: "Lead Data Scientist" at "ERICSSON" (2020-Present)
   - Add bullets or bullet groups

2. Add Job: "Senior Data Scientist" at "ERICSSON" (2019-2020)
   - Add bullets or bullet groups
```

## Button Reference

| Button | Color | What it Does |
|--------|-------|--------------|
| "+ Add Job" | Green | Adds a new job entry (top level) |
| "+ Add Bullet Point" | Blue (dashed) | Adds a bullet point to current context |
| "+ Add Bullet Group (Optional)" | Yellow (dashed) | Adds a category/group for organizing bullets |
| Delete (×) | Red | Deletes entry/bullet (appears on hover) |

## Keyboard Shortcuts

- **Enter** after typing bullet point → Saves the bullet
- **Enter** after typing group name → Saves the group
- **Escape** (future) → Cancel current action

## Contact Information

### Saving Contact Info
1. Click "✏️ Edit" button in Contact Information section
2. Fill in fields (all optional):
   - Email
   - Phone
   - Location
   - LinkedIn URL
   - GitHub URL
3. Click "Save"
4. Changes save immediately and auto-refresh!

### Viewing Contact Info
Contact info displays with icons:
- 📧 Email
- 📱 Phone
- 📍 Location
- 💼 LinkedIn (clickable link)
- 💻 GitHub (clickable link)

## Profile Management

### Deleting a Profile
1. Hover over profile tab
2. Click × button that appears
3. Confirm deletion
4. Next profile selected automatically

## Other Section Types

### Education
- Click "+ Add Degree"
- Structure: Degree → Bullet points (no grouping)
- Example: "PhD in Computer Science" → bullets about thesis, GPA, etc.

### Skills
- Click "+ Add Category"
- Structure: Category → Skills list
- Example: "Programming Languages" → Python, JavaScript, etc.

### Projects/Certifications/Awards
- Click "+ Add [Type]"
- Structure: Item → Bullet points (optional)
- Similar to Education

## Troubleshooting

### Not seeing updates?
- The page should auto-refresh now
- If you added this before the update, try manually refreshing once

### Bullet group not showing?
- Make sure you expanded the job entry first
- Bullet groups only appear for Work Experience section

### Can't find Add Job button?
- Make sure Work Experience section is expanded
- Button appears below section content

## Migration from Old Structure

If you had entries created before this update:
1. They will still work and display
2. Old "Role" sub-entries now act like bullet groups
3. Consider recreating for better organization
4. Or keep as-is if they work for you
