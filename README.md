# 🎯 Agentic CV Builder

**Version 2.0.0** - Intelligent AI-Powered CV Platform with Dual-AI Analysis

An intelligent CV platform that transforms how you create resumes. Build your complete professional profile once with unlimited hierarchical structure, then let dual-AI models (GPT-4o + Claude Sonnet 4.5) analyze jobs and intelligently **select** the best-matching content for each application - no AI-generated content, just smart selection from YOUR experiences.

---

## 🌟 Overview

The Agentic CV Builder is not just another resume template tool. It's an intelligent platform that:

- **Stores your complete professional history** in unlimited hierarchical structure
- **Analyzes job requirements** using two independent AI models for unbiased insights
- **Selects (never generates)** the most relevant content from YOUR experiences
- **Provides expert recruiter verdicts** on whether you should apply
- **Tracks your applications** with beautiful Kanban board visualization
- **Exports professional PDFs** in multiple ATS-optimized templates

> **Core Philosophy**: AI should **intelligently select** from your real experiences, not fabricate content. Your authenticity is your strength.

## 🚀 Complete 5-Step Workflow

### **Step 1: My Profile** 👤
**Your Professional Identity**

Set your core contact information that will be used across all generated CVs:
- Full name
- Phone number
- Email address
- LinkedIn profile
- GitHub profile
- Portfolio website

This information appears consistently on every tailored CV you create.

---

### **Step 2: Profile Pool** 📝
**Your Comprehensive Career Repository**

Build your complete professional story with **unlimited nested structure**:

#### **Flexible Content Organization**
- **Sections**: Work Experience, Skills, Education, Projects, Certifications, Awards, Publications, Languages
- **Entries**: Individual companies, degrees, projects, certifications
- **Sub-entries**: Different roles within the same company, nested project phases
- **Bullet Points**: Detailed achievements and responsibilities
- **Text Paragraphs**: Free-form descriptions and summaries

#### **Unlimited Hierarchical Depth**
```
Work Experience
  └─ Company A
      ├─ Role 1 (2020-2023)
      │   ├─ Bullet: Led team of 5 engineers...
      │   ├─ Bullet: Increased performance by 40%...
      │   └─ Sub-entry: Special Project Alpha
      │       ├─ Bullet: Developed microservices...
      │       └─ Bullet: Reduced latency by 60%...
      └─ Role 2 (2018-2020)
          ├─ Bullet: Managed $2M budget...
          └─ Bullet: Launched 3 major features...
```

**Add everything** - education details, every project, all certifications, complete skill lists. The AI will select what's relevant for each job.

---

### **Step 3: Tailor CV** ✨
**Dual-AI Magic in Action**

#### **Paste Any Job Description**
Simply paste the complete job posting, and watch the magic happen.

#### **Background AI Processing**
AI analysis runs in the background - continue working and return when ready. A global status bar shows progress across all pages.

#### **Three-Phase Analysis**

**Phase 1: Job Requirements Analysis**
- Both GPT-4o and Claude Sonnet 4.5 independently analyze:
  - Job category and seniority level
  - Required technical skills
  - Soft skills and competencies
  - Education requirements
  - Experience requirements
  - Preferred qualifications

**Phase 2: Profile Fit Analysis**
Each AI model provides:
- **Fit Percentage** (0-100%): How well you match the role
- **Strengths**: What makes you a strong candidate
- **Critical Gaps**: What's missing from your profile
- **Experience Match**: How your experience aligns
- **Technical Skills Match**: Percentage of required skills you have

**Phase 3: ATS Compatibility Analysis**
Each AI calculates:
- **Overall ATS Score** (0-100%): How well your CV passes ATS systems
- **Keyword Match**: Coverage of job-specific keywords
- **Skills Coverage**: Percentage of required skills present
- **Action Verbs Score**: Use of strong action verbs
- **Has Metrics**: Presence of quantifiable achievements

#### **Expert Recruiter Verdict**
Each AI provides:
- ✅ **Should Apply** or ❌ **Do Not Apply**
- Detailed reasoning for their recommendation
- Suggestions for improving your chances

#### **Intelligent Content Selection**
After analysis, AI models **select** (never generate) items from your Profile Pool:
- Summary items optimized for the role
- Work experiences with relevant achievements
- Skills categories matching job requirements
- Education, projects, certifications relevant to the position
- Awards and publications that demonstrate expertise

#### **Dual-AI Voting System**
- 🟢 **OpenAI badge**: Recommended by GPT-4o
- 🔵 **Claude badge**: Recommended by Claude Sonnet 4.5
- Items with **both badges** = strongest matches
- Each recommendation includes **reasoning** explaining why

## 🤖 Dual-AI Architecture

### **Why Two AI Models?**

Using both OpenAI GPT-4o and Anthropic Claude Sonnet 4.5 provides:

1. **Unbiased Analysis**: Two independent opinions reduce bias
2. **Higher Confidence**: Items recommended by both = strongest matches
3. **Diverse Perspectives**: Different AI architectures see different patterns
4. **Quality Validation**: Cross-verification improves accuracy
5. **Better Coverage**: Each AI might catch what the other misses

### **OpenAI GPT-4o**
- Latest multimodal model from OpenAI
- Excellent at structured analysis
- Strong technical skill extraction
- Precise ATS optimization

### **Anthropic Claude Sonnet 4.5**
- Anthropic's advanced reasoning model
- Superior at nuanced interpretation
- Excellent at identifying gaps
- Strong strategic recommendations

### **Selection Philosophy**
- **AI NEVER generates new content**
- **AI ONLY selects from your real experiences**
- **Your authenticity remains intact**
- **No fabricated achievements**
- **100% genuine, 100% optimized**

## 🚀 Getting Started

### **Prerequisites**
- Python 3.9+
- Node.js 16+
- PostgreSQL 13+
- OpenAI API Key
- Anthropic API Key

### **Quick Setup**

1. **Clone the repository**
   ```bash
   git clone <repository-url>
   cd agentic_work_profile
   ```

2. **Backend Setup**
   ```bash
   cd backend
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   pip install -r requirements.txt
   ```

3. **Create `.env` file in backend/**
   ```env
   DATABASE_URL=postgresql://user:password@localhost/dbname
   SECRET_KEY=your-secret-key-here
   OPENAI_API_KEY=sk-...
   ANTHROPIC_API_KEY=sk-ant-...
   ```

4. **Initialize Database**
   ```bash
   # Create tables
   python -c "from database import engine; from models import Base; Base.metadata.create_all(bind=engine)"
   ```

5. **Start Backend**
   ```bash
   uvicorn main:app --reload --port 8000
   ```

6. **Frontend Setup** (in new terminal)
   ```bash
   cd frontend
   npm install
   npm run dev
   ```

7. **Access Application**
   - Frontend: http://localhost:5173
   - Backend API: http://localhost:8000
   - API Docs: http://localhost:8000/docs

For detailed setup instructions, see [INSTALLATION.md](INSTALLATION.md)

## 📊 API Endpoints

### **Authentication**
- `POST /api/auth/register` - Register new user
- `POST /api/auth/login` - Login user
- `GET /api/auth/me` - Get current user

### **User Profile**
- `GET /api/user/profile` - Get user contact info
- `PUT /api/user/profile` - Update user contact info

### **Master Profile**
- `GET /api/profile` - Get complete profile
- `POST /api/profile/sections` - Create section
- `POST /api/profile/entries` - Create entry
- `POST /api/profile/items` - Create item
- `PUT /api/profile/items/{id}` - Update item
- `DELETE /api/profile/items/{id}` - Delete item

### **AI Analysis**
- `POST /api/job/analyze` - Analyze job description
- `POST /api/job/analyze-fit` - Analyze profile fit
- `POST /api/cv/tailor` - Get AI recommendations

### **Tailored CVs**
- `GET /api/cv/tailored-versions` - List all CVs
- `POST /api/cv/tailored-versions` - Save new CV
- `GET /api/cv/tailored-versions/{id}` - Get CV details
- `PUT /api/cv/tailored-versions/{id}` - Update CV
- `DELETE /api/cv/tailored-versions/{id}` - Delete CV
- `POST /api/cv/tailored-versions/{id}/pdf` - Generate PDF

### **Application Tracker**
- `GET /api/applications` - List applications
- `POST /api/applications` - Create application
- `PUT /api/applications/{id}` - Update application
- `PUT /api/applications/{id}/status` - Update status
- `DELETE /api/applications/{id}` - Delete application
